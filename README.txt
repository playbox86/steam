PLAYBOX STEAM — ОПТИМИЗИРОВАННАЯ ВЕРСИЯ

На сайт загружать рядом:
- index.html
- steam_catalog_data.js
- steam_catalog_details.js

steam_catalog.py остаётся на компьютере и при следующем полном запуске сам создаст оба JS-файла в оптимизированном формате.

Обычный запуск:
  py steam_catalog.py

Продолжить после сбоя:
  py steam_catalog.py resume

Что изменено:
- на странице одновременно создаётся только 60 карточек;
- страницы Назад/Вперёд вместо 63 000 DOM-карточек сразу;
- поиск с задержкой 180 мс;
- быстрый search_text вместо обхода каждого DLC на каждую букву;
- DLC/игровая валюта вынесены в steam_catalog_details.js и загружаются только при первом открытии дополнений;
- основной data.js уменьшен с ~153 MiB до ~38 MiB для текущего каталога;
- details.js ~8.5 MiB и не грузится при первом открытии страницы.
